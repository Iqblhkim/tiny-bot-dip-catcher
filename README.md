# Dip-Catcher Bot — Tiny Bot, Easy $2: Beat Buy-and-Hold on Solana

A tiny paper-trading bot for hourly Solana prices. Long-only, deterministic,
pure Python stdlib. It buys sharp dips (close >= 3.5% below its close 10 bars
ago) and holds for the bounce, plus a small scalp layer that keeps the entry
above the 8-trade guardrail in quiet windows.

Dev window (local grade): **+$227.77 net PnL, 26 trades, 3.5% max drawdown**
vs buy-and-hold **-$869.34** on the same window.
